# Portofolio.Elfrana De Ridwan

Personal engineering portfolio website — built with HTML, CSS (Bootstrap 5), JavaScript, and Python (Flask for local development).

## Live Site
🔗 [elfranar.github.io](https://elfranar.github.io)

## Tech Stack
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Backend (local dev only)**: Python 3 + Flask
- **Engineering Tools**: AutoCAD, ASPEN HYSYS, Excel Solver

## Local Development

```powershell
# 1. Activate virtual environment
.\.venv\Scripts\activate

# 2. Run Flask server
python app.py

# 3. Open browser at http://127.0.0.1:5000
```

## GitHub Pages Deployment

The `docs/` folder contains the **fully static version** of the site (no Flask required).

GitHub Pages is configured to serve from the `docs/` folder of the `main` branch.
